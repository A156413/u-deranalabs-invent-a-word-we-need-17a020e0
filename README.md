Coins a new English word for a moment everyone knows: **doorjog** — the awkward half-jog you break into when someone holds a door open for you from too far away. A tiny program that writes the word and its one-line definition to `/output/entry.txt` for make.fun's "Invent a Word We Need" bounty.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
